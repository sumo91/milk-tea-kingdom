奶茶王国 Web smoke（手机 Safari，Wi-Fi）

通过标准是硬刷新后进入主界面 HUD，不是「链接能开」或「?v= 变了」。

1. 本机 Godot 4.7 导出 Web 之后跑：
   sh tools/web_deploy_tip.sh
   确认最后一项是 ensureCrossOriginIsolationHeaders=false。
   为 true 时脚本会失败，不要部署。
2. 把脚本打出的整段 URL（带 ?v= 短哈希）发到手机。Safari 用这个新链接打开。
   已经开过旧页面时：关掉该标签再打开新 ?v=，或按住刷新。不要只看地址栏哈希。
3. 启动卡必须依次出现（系统中文字体，不依赖游戏内子集）：
   - 下载资源… 32%（百分号前有空格），下面有 x.x / y.y MB，数字在涨
   - 下载结束后 加载游戏…（Safari 编译 wasm 时可能还要等一会儿，字不能停在无进度的 Godot 闪屏上）
   - 马上好…
   - 然后进入主 HUD
4. 主 HUD 才算通过：能看见标题「奶茶王国」、三站（茶园 / 调制台 / 摊位）、升级列表。
   只有新的 ?v=、只有布局壳、或一直停在闪屏，都是失败。
5. 竖屏应铺满宽度（不要左右大黑边）。点一次升级，或离开超过 1 分钟再打开以确认离线弹窗。
6. 若 MB 数字在涨，就不是 404。若十几秒完全没字、没百分比，记失败并看是否清过站点缓存。

以后若要自动化（可选，现在不用做）：
打开带 ?v= 的 Pages 地址，等到启动遮罩消失且画面在画，再断言 HUD 文案（奶茶王国 / 三站）或做截图对比。
HTTP 200 或 ?v= 变化本身不能当通过。
