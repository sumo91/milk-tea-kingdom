| CJK / 可读色 | 深字浅底；禁止白字贴浅底；色板见 `readable-palette-hierarchy.md` | Theme 未完整套色板；部分 `_temp` 当主信息 | **P1** | 程序（Theme） |

## 验收（给程序 / 制作人）

- [ ] 竖屏 720×1280 打开无硬横屏缩放感  
- [ ] 分区顺序：资源顶 → 站中 → 升级底  
- [ ] 主按钮热区 ≥48；安全区边距达标  
- [ ] Theme 套可读色板后，数字可读、非灰盒纯调试感
