# V0-M 竖屏线框优先级（给 Idle系统程序）

对照：`kingdom-mockups/01-main-hud.jpg` · 线框图：`v0m-portrait-wireframe.png`  
设计分辨率：**720×1280**（portrait）  
安全区：顶 **≥48** · 底 **≥34** · 左右 **≥16** · 可点热区 **≥48×48**

---

## P0 — 仅布局（可继续 `_temp` 皮）

### 1. 工程切竖屏
- 项目/窗口/导出改为 **720×1280** portrait（stretch：canvas_items / expand 可保留，但逻辑布局按竖屏锚点）
- 去掉依赖「整屏=1280×720 横排」的硬编码坐标

### 2. 主屏垂直重建（四区）

| 区 | Y 建议（含安全区后内容区约 720×1198） | 内容 | 高约 |
| --- | --- | --- | --- |
| A 顶栏 | y≈48 起 | 标题「奶茶王国」+ 声望细条（Lv / 进度） | **88–110** |
| B 资源 | A 下 | **三轨竖叠**：茶叶 / 成品 / 金币（金币可无进度仅存量） | **每轨 44–52**，轨间距 8 → 合计 **~160** |
| C 三站 | B 下 | **三张站卡竖排** SHELF → BREW → STALL（SEAL 暂隐藏） | **每卡 100–120**，间距 8 → 合计 **~340** |
| D 升级 | 底 / 抽屉 | 「升级」标题 + **可滚动卡列表**（底锚，或底部抽屉默认展开一半） | **余量 ≥280**；单卡高 **72–88**；按钮高 **≥48** |

信息流（必须）：**标题+声望 → 三资源 → 三站 → 升级底**。  
禁止：继续用「左站 / 中舞台 / 右升级」三栏当手机主布局。

### 3. 安全与热区
- 左右内容 inset ≥16；顶≥48；底≥34（含 Home Indicator 假想）
- 升级钮、资源「+」、站卡可点区 ≥48 高
- 站卡：左 64 图标槽 · 中站名+Lv/`+N` · 右可选小钮

### 4. P0 不做
- 不换正式插画/店景  
- 不接 SEAL  
- 可不做中区舞台大图（站卡占中即可）
